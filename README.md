## Shorin Arch Setup

## 使用方法

```
curl -L shorin.xyz/archsetup | bash 
```

详情见：[ShorinWiki_一键安装桌面环境](https://github.com/SHORiN-KiWATA/Shorin-ArchLinux-Guide/blob/main/wiki/archlinux/%E4%B8%80%E9%94%AE%E9%85%8D%E7%BD%AE%E6%A1%8C%E9%9D%A2%E7%8E%AF%E5%A2%83.md)

## QQ

一键配置的桌面环境都预装了 [linuxqq-wayland-fix](https://github.com/SHORiN-KiWATA/linuxqq-wayland-fix)，修复 QQ 以 Wayland 运行时屏幕共享、共享电脑声音和剪贴板的问题。请从应用菜单的「QQ（Wayland修复版）」打开 QQ。
